# Indexers

Envio is the data layer for blockchain apps. It gives Optopia developers the fastest, most flexible way to get real-time and historical onchain data, from a single GraphQL API to raw high-speed access, with managed hosting on Envio Cloud.

## Envio

[Envio](https://envio.dev/?utm_source=optopia&utm_medium=partner-docs) is a data indexing framework for building backends that serve onchain data to your app.

HyperIndex, the Envio indexing framework, supports any EVM network out of the box using your own RPC endpoint, so you can index Optopia by pointing it at an Optopia RPC. You define the events and entities you care about, and HyperIndex serves them through a ready to use GraphQL API.

### Features

* Real-time and historical onchain data through a single GraphQL API
* Works with any EVM chain via your own RPC endpoint
* Flexible schema and event handlers written in familiar languages
* Managed hosting on Envio Cloud, or self host wherever you prefer
